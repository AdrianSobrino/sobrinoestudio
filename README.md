# Sobrino Estudio — Portfolio

Minimal one-page filmmaker portfolio for GitHub Pages.

## What is included
- Sobrino Estudio branding
- 3 Vimeo projects
- Contact email
- Instagram and Vimeo links
- Responsive layout for desktop and mobile
- No project names, as requested

## Publish for free on GitHub Pages
1. Create a public GitHub repository. For the simplest personal-site URL, use `<github-username>.github.io`.
2. Upload `index.html` and `style.css` from this folder.
3. In GitHub: Settings → Pages → Deploy from a branch → `main` → `/root`.
4. GitHub will publish the site at your Pages URL.

The video thumbnails use Vumbnail's generated Vimeo thumbnails. Clicking a project opens the Vimeo page.
